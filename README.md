# FabStudio – Virtual Try-On

See clothes on you, live. This is a Manifest V3 Chrome and Edge extension (version 0.1.0). Pose tracking and garment cut-out run on your computer with MediaPipe. Nothing from the camera is uploaded.

Build the extension, load the `dist` folder in the browser, and use the side panel as described in the [user guide](USER_GUIDE.md). A short note for a pre-built zip is in [INSTALL.txt](INSTALL.txt).
